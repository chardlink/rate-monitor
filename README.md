# 🌍 汇率实时提醒助手 | 跨境结汇利器

这是一个专为跨境电商卖家打造的**汇率实时监控与到价提醒助手**。支持离岸人民币 CNH，深度适配万里汇（WorldFirst）、Wise、连连支付等主流结汇收款平台，帮助你捕捉最佳结汇时机，锁定最高利润。

---

## 🌟 核心特色功能

1.  **官方数据源与平滑容灾降级**：
    *   **主数据源**：支持配置 **Open Exchange Rates 官方源**，获取每小时高频更新的真实 **CNH 离岸人民币** 报价。
    *   **免密钥备用源**：若未配置密钥，系统将自动降级使用免密钥的 **Open ER-API** 与 **FawazAhmed**（每日更新）。
    *   **离岸价差警告**：若因接口故障导致降级为无真实 CNH 的数据源，系统会智能采用在岸 CNY 并亮起 `⚠ CNH ≈ CNY` 提示，防止价差误导。
2.  **多平台结汇独立配置**：
    *   支持管理**万里汇、Wise、连连支付**等多个收款账户，可自由新增/删除/编辑平台。
    *   可自定义设置**点差扣费百分比 (%)** 以及 **估算偏差校准（手动微调偏移量）**，让估算结汇价与平台手机 App 屏幕上的数值完全吻合。
3.  **多维度到价提醒**：
    *   支持设置“高于目标值时提醒”或“低于目标值时提醒”。
    *   **判定依据灵活选择**：可选择以“市场参考价”或收款平台扣费后的“平台估算价”作为到价判定和警报依据。
    *   支持**网页提示音、浏览器 Toast 及顶部横幅**三重强效提醒。
4.  **极速渲染与离线缓存**：
    *   引入 **秒开首屏机制**，优先载入本地历史缓存数据，杜绝白屏等待；随后后台自动刷新拉取最新数据。
    *   **网络断网防护**：若因境外 API 被屏蔽或网络彻底断开，系统会自动启用最后一次拉取成功的离线缓存数据，保障换算与历史统计功能完全可用。
5.  **精美走势图表与行情板**：
    *   搭载贝塞尔高平滑度折线 Canvas 走势图，支持 1h/6h/24h 采样区间切换。
    *   多货币行情板包含 10 种商贸核心货种，支持一键切换监控币对。

## 🛠️ 部署指南

本系统为纯前端静态应用，支持多样化的一键式零门槛部署：

### 方案 1：直接本地运行（零门槛）
无需安装任何服务器，将代码包下载到电脑后，直接双击 **`index.html`** 文件，即可在任意浏览器中完美启动运行。

---

### 方案 2：群晖 NAS 部署（免下载源码，极力推荐）
得益于 GitHub 容器镜像仓库（GHCR）的自动构建，你**不需要下载任何源码文件**，只需直接利用群晖的 **Container Manager** 套件即可一键部署：

1.  打开群晖 NAS 的 **Container Manager**。
2.  点击 **`项目` (Projects)** -> **`新增` (Create)**。
3.  选择合适的路径，在数据源处选择“使用 docker-compose.yml 创建项目”，并粘贴以下 **8 行配置** 即可：

```yaml
version: '3.8'

services:
  rate-monitor:
    image: ghcr.io/chardlink/rate-monitor:latest  # 云端自动拉取最新的公开打包镜像
    container_name: rate-monitor-app
    ports:
      - "8080:80"  # 将群晖的 8080 端口映射到容器。你可以自由更换为 8081 等其他端口
    restart: always
```
4.  保存运行后，在浏览器访问 `http://<群晖NAS局域网IP>:8080` 即可开始使用。

---

### 方案 3：Ubuntu / Linux 终端部署

如果要在你的 Ubuntu 云服务器或本地 Linux 机器上部署，直接运行以下命令：

```bash
# 1. 克隆代码仓库
git clone https://github.com/chardlink/rate-monitor.git

# 2. 进入项目目录
cd rate-monitor

# 3. 使用 Docker Compose 一键启动服务
sudo docker-compose up -d --build
```
启动成功后，通过浏览器访问 `http://<服务器IP>:8080` 即可。

## 📝 官方点差配置参考值

为了让你的“平台估算结汇价”最贴近手机 App 显示的实时成交价格，建议在**平台结汇配置**中输入以下标准参数进行校准：

| 收款平台 | 默认标准点差费率 | 手动校准偏差量 (Offset) 推荐值 | 平台优势简介 |
| :--- | :--- | :--- | :--- |
| **万里汇 (WorldFirst)** | **`0.38%`** | **`-0.0037`** | 蚂蚁集团旗下，费率极具竞争力，大客户可申请更低专属费率。 |
| **LianLian Pay (连连支付)** | **`0.40%`** (亚马逊封顶) | **`0.0000`** | 针对 TikTok Shop/TEMU 等新兴平台提现费率可低至 `0.20%`。 |
| **Wise** | **`0.45%`** (平均费率) | **`0.0000`** | 透明中间价，无任何隐藏汇率加价，非常适合灵活多币种换算。 |
