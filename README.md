# 🌍 汇率实时提醒助手 | 跨境结汇利器

这是一个专为跨境电商卖家与外贸从业者打造的**汇率实时监控与到价提醒助手**。系统支持离岸人民币 CNH，深度适配万里汇（WorldFirst）、Wise、连连支付等主流结汇收款平台，帮助你在第一时间捕捉最佳结汇时机，锁定最高利润，无需整天盯着屏幕。

---

## 🌟 核心实用功能

1.  **🎯 24小时无人值守到价提醒**：
    *   支持设置“高于目标值”或“低于目标值”时提醒。
    *   **判定依据灵活选择**：不仅能根据“市场参考价”提醒，还能根据扣除收款平台手续费后的“平台估算到账价”进行判定。
    *   达标时，网页端将通过**警报提示音、显眼横幅和Toast气泡**进行多重强效提醒。
2.  **🔔 手机多通道即时推送**：
    *   支持将达标警报发送到您的**手机微信（通过 Pushplus）、飞书群机器人、钉钉群机器人、或个人邮箱**。
    *   多个推送渠道可同时勾选。只要汇率达标，手机立刻收到推送，即使出门在外也能第一时间知晓并进行结汇操作。
3.  **🏦 贴合真实的结汇价估算**：
    *   可自定义设置收款平台的**点差扣费百分比 (%)** 以及 **估算偏差校准（微调偏移量）**，让系统算出的估算结汇价与你手机 App 上的真实结汇价完全吻合。
4.  **📊 汇率走势与多货币行情**：
    *   支持 **12小时、24小时、7天、15天、30天** 多个周期的历史汇率走势图，最高值、最低值、均值一目了然，方便研判趋势。
    *   行情板支持美金对离岸人民币（CNH）、在岸人民币（CNY）、欧元、英镑、日元等 10 种商贸核心货种，支持一键切换主监控交易对。
5.  **🛡️ 极简防误触设计**：
    *   **开关安全收纳**：所有推送通道的详细配置和“启用开关”均收纳在配置弹窗中，防止在主页误触关闭监控。
    *   **防警报轰炸**：采用自愈状态锁机制。汇率达标时手机只推送一次，直到汇率回调至安全区间自愈，或者您手动修改规则后，才会触发下一次提醒，避免被频繁的消息轰炸。
6.  **⚡ 零等待加载与断网容灾**：
    *   页面开启时优先使用本地缓存数据瞬间载入，杜绝网络差时的白屏等待。
    *   若云端接口发生故障或断网，系统自动降级使用备用源，并提示汇率更新状态，保障计算器与换算功能始终可用。

为了让您选择最适合的运行方式，请在部署前了解 **双击网页运行（单机版）** 与 **24小时服务器运行（容器版/原生服务版）** 的核心差异：

| 功能对比 | 方式 1：双击本地运行（单机网页版） | 方式 2/3：服务器部署版（容器版/服务版） |
| :--- | :--- | :--- |
| **监控可靠性** | ❌ **依赖网页开启**：必须一直开着浏览器标签页。网页一旦关闭，监控立即停止。 | 🌊 **24小时后台静默监控**：服务器后台自动抓取，电脑关机、网页关闭均不影响监控。 |
| **历史走势记录** | ⚠️ **仅记录当前显示币对**：仅在网页打开时，记录并累积当前屏幕上**正在显示**的这一个交易对的历史。关闭网页后所有币对均不会被动记录。 | 📈 **全币种同时记录**：服务端每小时自动下载并储存所有支持的币种汇率，任何时候切换均有完整小时级走势。 |
| **到价手机推送** | ❌ **不支持**：因浏览器沙箱与跨域限制，无法在后台发送微信、飞书、钉钉消息或邮件。仅在网页开着时发出本地声音/横幅提醒。 | 🔔 **支持多渠道手机推送**：微信、飞书、钉钉、邮件实时并行推送至手机，人不在电脑前也能第一时间接收提醒。 |
| **使用场景推荐** | 适合临时打开，快速换算汇率、研判近期走势。 | 🚀 **强烈推荐**。适合需要长效静默监控、期望在手机上第一时间收到汇率变动提醒的跨境人。 |

## 🛠️ 部署与使用指南

无论是在个人电脑上直接双击打开，还是在私有云/群晖 NAS 服务器上 24 小时运行，系统均能完美支持：

### 方式 1：双击本地运行（单机版）
无需安装任何服务器，将代码包下载到电脑后，直接双击 **`index.html`** 文件，即可在任意浏览器中完美启动运行。

### 方式 2：群晖 NAS 容器部署（24 小时静默监控，推荐）
利用群晖的 **Container Manager** (旧版叫 Docker) 套件，无需下载源码即可一键启动：
1.  **准备文件夹**：打开群晖的 `File Station`，在 `docker` 文件夹下新建一个名为 `rate-monitor` 的文件夹，并在其内部新建一个名为 `data` 的子文件夹。
2.  **创建项目**：
    *   打开 **Container Manager** -> **项目** -> **新增**。
    *   **项目名称**：输入 `rate-monitor`。
    *   **路径**：选择刚才新建的 `/docker/rate-monitor` 文件夹。
    *   **来源**：选择 **“创建 docker-compose.yml”**，并在配置框中贴入以下配置：

```yaml
version: '3.8'

services:
  rate-monitor:
    image: chardchao/rate-monitor:latest  # 自动拉取最新公开镜像
    container_name: rate-monitor-app
    ports:
      - "1180:1180"  # 浏览器访问端口，可根据占用情况修改
    volumes:
      - ./data:/usr/src/app/data  # 挂载数据卷以保存您的提醒规则与密钥
    restart: always
```
3. 保存运行后，在浏览器访问 `http://<您的群晖IP>:1180` 即可。

> 💡 **国内网络提示**：本镜像托管于 **Docker Hub**（`chardchao/rate-monitor:latest`），国内网络可直接拉取，无需额外代理。如您的群晖已在 Container Manager 中配置了 Docker Hub 镜像加速源，拉取速度将更快。


### 方式 3：Ubuntu / Linux 服务器部署
您可以根据喜好选择 **一键脚本原生部署** 或 **Docker 容器部署**：

#### 选项 A：一键 Shell 脚本原生部署（无需安装 Docker，最方便）
如果您的服务器未安装 Docker，可以使用我们专门设计的一键自动部署脚本。该脚本会自动帮您配置 Node.js 运行环境与 PM2 进程守护工具，自动配置开机自启，并静默挂起 24 小时监控后台。

您只需在 Ubuntu/Linux 服务器终端执行以下一行命令即可：
```bash
wget -O install.sh https://raw.githubusercontent.com/chardlink/rate-monitor/main/install.sh && sudo bash install.sh
```
部署成功后，会显示服务器的访问 IP 以及 PM2 管理命令。

#### 选项 B：Docker / Docker Compose 容器部署
若您偏好使用容器化部署，且服务器已安装 Docker，您可以在项目目录下创建 `docker-compose.yml` 配置文件（镜像地址使用 `chardchao/rate-monitor:latest`，其余配置内容同上面的群晖方式 2），并在终端执行以下命令：
```bash
docker compose up -d
```
或者您也可以直接克隆 GitHub 仓库代码并一键启动：
```bash
# 1. 克隆代码仓库
git clone https://github.com/chardlink/rate-monitor.git

# 2. 进入项目目录并启动
cd rate-monitor && sudo docker compose up -d
```
启动成功后，通过浏览器访问 `http://<服务器IP>:1180` 即可。
