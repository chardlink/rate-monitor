# 🌍 汇率实时提醒助手 | 跨境结汇利器

这是一个专为跨境电商卖家与外贸从业者打造的**汇率实时监控与到价提醒助手**。系统支持离岸人民币 CNH，深度适配万里汇（WorldFirst）、Wise、连连支付等主流结汇收款平台，帮助你第一时间捕捉最佳结汇时机，锁定最高利润，无需整天盯着屏幕。

---

## 🌟 核心实用功能

1.  **🎯 24小时无人值守到价提醒**：
    *   支持设置“高于目标值”或“低于目标值”时提醒。
    *   **判定依据灵活选择**：不仅能根据“市场参考价”提醒，还能根据扣除收款平台手续费后的“平台估算到账价”进行判定。
    *   达标时，网页端将通过**警报提示音、显眼横幅和Toast气泡**进行多重强效提醒。
2.  **🔔 手机多通道即时推送**：
    *   支持将达标警报发送到您的**手机微信（通过 Pushplus）、飞书群机器人、钉钉群机器人、或个人邮箱**。
    *   多个推送渠道可同时勾选。只要汇率达标，手机立刻收到推送，即使出门在外也能第一时间知晓并进行结汇操作。
3.  **🏦 贴合真实的结汇价估算**：
    *   可自定义设置收款平台的**点差扣费百分比 (%)** 以及 **估算偏差校准（微调偏移量）**，让系统算出的估算结汇价与你手机 App 上的真实结汇价完全吻合。
4.  **📊 汇率走势与多货币行情**：
    *   支持 **12小时、24小时、7天、15天、30天** 多个周期的历史汇率走势图，最高值、最低值、均值一目了然，方便研判趋势。
    *   行情板支持美金对离岸人民币（CNH）、在岸人民币（CNY）、欧元、英镑、日元等 10 种商贸核心货种，支持一键切换主监控交易对。
5.  **🛡️ 极简防误触设计**：
    *   **开关安全收纳**：所有推送通道的详细配置和“启用开关”均收纳在配置弹窗中，防止在主页误触关闭监控。
    *   **防警报轰炸**：采用自愈状态锁机制。汇率达标时手机只推送一次，直到汇率回调至安全区间自愈，或者您手动修改规则后，才会触发下一次提醒，避免被频繁的消息轰炸。
6.  **⚡ 零等待加载与断网容灾**：
    *   页面开启时优先使用本地缓存数据瞬间载入，杜绝网络差时的白屏等待。
    *   若云端接口发生故障或断网，系统自动降级使用备用源，并提示汇率更新状态，保障计算器与换算功能始终可用。

## 🛠️ 部署与使用指南

无论是在个人电脑上直接双击打开，还是在私有云/群晖 NAS 服务器上 24 小时运行，系统均能完美支持：

### 方式 1：双击本地运行（单机版）
无需安装任何服务器，将代码包下载到电脑后，直接双击 **`index.html`** 文件，即可在任意浏览器中完美启动运行。

### 方式 2：群晖 NAS 容器部署（24 小时静默监控，推荐）
利用群晖的 **Container Manager** (或 Docker) 套件，无需下载源码即可一键启动：
1.  在群晖 `docker` 目录下新建 `rate-monitor/data` 文件夹。
2.  在 **Container Manager** 中新建项目，选择“创建 docker-compose.yml”并输入以下配置：

```yaml
version: '3.8'

services:
  rate-monitor:
    image: ghcr.io/chardlink/rate-monitor:latest  # 自动拉取最新公开镜像
    container_name: rate-monitor-app
    ports:
      - "8080:80"  # 浏览器访问端口，可根据群晖占用情况修改
    volumes:
      - ./data:/usr/src/app/data  # 挂载数据卷以保存您的提醒规则与密钥
    restart: always
```
3. 保存运行后，在浏览器访问 `http://<您的群晖IP>:8080` 即可。

### 方式 3：Ubuntu / Linux 服务器部署
在您的 Linux 服务器终端中，新建一个目录并创建 `docker-compose.yml`（配置同上），然后执行命令启动：
```bash
docker compose up -d
```
